# Life Dashboard

Life Dashboard is a beginner-friendly web application for organizing daily tasks, running a 25-minute focus session, and saving favorite website links.

## Features

- Current time, date, and time-based greeting
- Custom name saved in Local Storage
- 25-minute focus timer with start, stop, and reset controls
- Add, edit, complete, and delete tasks
- Duplicate task prevention
- Quick Links saved in Local Storage
- Light and dark mode
- Responsive layout for desktop and mobile

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Browser Local Storage API
