# Life Dashboard Project Guidance

This project is a beginner coding camp assignment.

## Technical constraints

- Use HTML for page structure.
- Use only `css/style.css` for styling.
- Use only `js/script.js` for application logic.
- Use Vanilla JavaScript without React, Vue, or another framework.
- Do not use a backend server.
- Store tasks, links, name, and theme in the browser Local Storage API.
- Keep the project responsive, readable, and compatible with modern browsers.

## Required features

- Current time, date, and time-based greeting
- 25-minute timer with start, stop, and reset buttons
- Task creation, editing, completion, deletion, and Local Storage persistence
- Quick Link creation, opening, deletion, and Local Storage persistence

## Selected challenges

- Light and dark mode
- Custom name in greeting
- Prevent duplicate tasks
